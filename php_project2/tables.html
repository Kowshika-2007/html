HTML Table Introduction

HTML tables are used to display data in rows and columns. The <table> tag is used to create a table. 

<table>
</table>

Table Elements

  • <table> - Creates a table
  • <tr> - Table Row
  • <th> - Table Heading
  • <td> - Table Data
  • <caption> - Table Title

Simple Table

<table border="1">
<tr>
<th>Name</th>
<th>Age</th>
</tr>

<tr>
<td>John</td>
<td>20</td>
</tr>
</table>
