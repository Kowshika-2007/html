HTML Images Introduction

Images make web pages more attractive and informative. HTML uses the <img> tag to display images. 

<img src="image.jpg" alt="Image">

Image Tag

The basic syntax is:

<img src="flower.jpg" alt="Flower">

The src attribute specifies the image location, and alt displays alternate text if the image cannot be loaded.

Image Attributes

Attribute Description
src Image Path
alt Alternative Text
width Image Width
height Image Height

Local Image

<img src="flower.jpg"
width="300"
height="200"
alt="Flower">

If flower.jpg is in the same folder as your HTML file, the image will be displayed.

Online Image

<img src="https://via.placeholder.com/300x200"
alt="Sample Image">

Clickable Image

<a href="https://www.google.com">
<img src="flower.jpg">
</a>

Click the image to open Google.
